# Norton D'Silva — Creative Director & Video Editor Portfolio

A state-of-the-art interactive portfolio website featuring 60fps/120fps hardware-accelerated scroll scrubbing, rich frosted glassmorphism, responsive YouTube showcase embeds, and direct WhatsApp contact integration.

## 🚀 Features

- **High-Performance Scroll Animation**: 240 full HD frames optimized into high-efficiency WebP sequence (`~17MB` total payload) with zero-reflow physics lerp rendering.
- **Frosted Glass Design System**: Multi-layered backdrop blurs, ambient studio lighting vignettes, dynamic hover glows, and crisp typography (`Oswald` + `Plus Jakarta Sans`).
- **Featured Works**: Embedded responsive 16:9 YouTube video showcases featuring award-winning music videos and commercial campaigns.
- **Core Services**: Detailed breakdowns for **Video Direction** and **Video Editing**.
- **Client Testimonials**: Verified creator & executive praise cards with custom author portraits.
- **Direct WhatsApp Chat**: One-click floating WhatsApp quick-connect pill (`+91 82080 83210`) with live online pulsing indicator.
- **Universal Multi-Device Responsiveness**: Tailored layouts for desktops, laptops, tablets, and smartphones with mobile glass drawer navigation.

## 🛠️ Tech Stack

- **HTML5 & Modern Semantic Architecture**
- **Vanilla CSS3** (Custom Glassmorphism, CSS Grid, Fluid Typography, Micro-interactions)
- **Vanilla JavaScript (ES6+)** (Physics-based `requestAnimationFrame` lerp engine, Intersection Observer)
- **Node.js** (Zero-dependency HTTP dev server)

## 🏃 Local Development

1. Clone the repository:
   ```bash
   git clone https://github.com/fahadsirkazi2006/portfolio.git
   cd portfolio
   ```

2. Start the local server:
   ```bash
   node server.js
   ```

3. Open in your browser:
   ```
   http://localhost:3000
   ```
